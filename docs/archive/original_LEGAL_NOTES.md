## This Remake

- This is a **fan remake / rebuild** using the original mod as a gameplay reference
- The original Witchery textures extracted from the jar are used as **placeholders** during development
- Decompiled source code is used as a **direct reference and starting point** where practical
- Logic that works well is reused and adapted to modern NeoForge APIs; logic that can be improved is rewritten
- The goal is a working, accurate remake — not a ground-up reimplementation for its own sake
