## Batch 21 Original Backup

This directory stores the live pre-remaster versions of the infernal contract family before their unique `32x32` redraw pass.

### Purpose

- Preserve the old contract-family sprites for side-by-side comparison.
- Record the point where the contract set was rebuilt from a shared high-resolution concept reference and unified parchment/seal language.
