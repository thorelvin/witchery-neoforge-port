## Batch 22 Original Backup

This directory stores the live pre-remaster versions of the Dream Weave family before their unique `32x32` redraw pass.

### Purpose

- Preserve both the raw weave inserts and finished Dream Weaver variants for side-by-side comparison.
- Record the point where the family was rebuilt from a shared high-resolution concept sheet and paired woven-tile language.
