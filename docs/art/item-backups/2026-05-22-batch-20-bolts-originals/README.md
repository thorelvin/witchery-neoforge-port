## Batch 20 Original Backup

This directory stores the live pre-remaster versions of the ritual bolt family before their unique `32x32` redraw pass.

### Purpose

- Preserve the old bolt-family sprites for side-by-side comparison.
- Record the point where the stake, anti-magic, holy, and splitting bolts were rebuilt from a shared high-resolution concept reference and unified projectile base.

### Files

- `ingredient.bolt_stake.png`
- `ingredient.bolt_anti_magic.png`
- `ingredient.bolt_holy.png`
- `ingredient.bolt_splitting.png`
