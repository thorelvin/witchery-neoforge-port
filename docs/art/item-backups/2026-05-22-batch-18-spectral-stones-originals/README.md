## Batch 18 Original Backup

This directory stores the live pre-remaster versions of the Spectral Stone family before their unique `32x32` redraw pass.

### Purpose

- Preserve the old spectral-stone family icons for side-by-side comparison.
- Record the point where the base stone and its spectre, banshee, and poltergeist variants were rebuilt from a shared high-resolution concept reference.

### Files

- `witchery.spectralstone.png`
- `witchery.spectralstone.spectre.png`
- `witchery.spectralstone.banshee.png`
- `witchery.spectralstone.poltergeist.png`
