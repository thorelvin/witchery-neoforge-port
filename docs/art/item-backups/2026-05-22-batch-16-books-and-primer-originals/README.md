## Batch 16 Original Backup

This directory stores the live pre-remaster versions of the Primer and specialist book family before their unique `32x32` redraw pass.

### Purpose

- Preserve the old visible book-family outliers for side-by-side comparison.
- Record the point where the Primer and eight specialist handbooks were rebuilt from one shared original grimoire base plus saved concept reference.
