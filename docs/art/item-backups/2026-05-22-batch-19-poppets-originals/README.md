## Batch 19 Original Backup

This directory stores the live pre-remaster versions of the poppet family before their unique `32x32` redraw pass.

### Purpose

- Preserve the old poppet-family sprites for side-by-side comparison.
- Record the point where the full rag-doll line was rebuilt from a shared high-resolution concept sheet and unified base silhouette.
